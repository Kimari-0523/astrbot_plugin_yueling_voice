# 柚铃语音助手

为 AstrBot 提供群聊分场景语音回复、中英日分段配音及音色设置。语音与文字使用同一轮最终答复，不单独生成另一份回答。

## 功能

- **自动回复与 @回复分别设置**：各自选择仅文字、仅语音、文字＋语音或随机，各自设置随机概率。
- **私聊独立模式**：仅文字、按需、每次或随机；按需模式遇到语音消息或明确朗读请求时附带语音。
- **中英日音色独立设置**：中文跟随提供商，英文默认 Ana，日语默认 Nanami；支持指定朗读语言、语速和音调。
- 混合文字按段落和句子选音色，按原顺序合并成一条语音；默认朗读上限 600 字。
- 保留现有会话、人格、历史和工具；可开启上下文衔接提示。模型仍可能误解上下文，提示不能替代模型能力。
- 总开关、群白名单、明确文字优先、合成失败回退文字、重复发送保护。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| AstrBot | `>=4.28,<5`，在 4.28.2 验证 |
| Python | 3.12 或更高，遵循 AstrBot 的环境要求 |
| 平台 | QQ 官方接口 `qq_official`、OneBot `aiocqhttp`；语音发送能力取决于适配器 |
| TTS | AstrBot 原生 `edge_tts` 提供商；自动分语言音色仅对该提供商生效 |
| 系统依赖 | FFmpeg；QQ 语音编码相关依赖由 AstrBot 和适配器提供 |

## 安装

在 AstrBot 后台的插件页面选择“从链接安装”，填写：

```text
https://github.com/Kimari-0523/astrbot_plugin_yueling_voice
```

也可下载本仓库 ZIP 后“从文件安装”。Python 依赖声明见 `requirements.txt`。手动部署时，在 **AstrBot 使用的 Python 环境** 执行：

```bash
python -m pip install -r requirements.txt
```

安装后启用插件。请先确认平台自身能够发送普通语音。

## 配置语音服务

1. 在“模型提供商 → 文字转语音”添加并启用 `edge_tts`，选择为当前配置使用的 TTS 提供商。
2. 中文推荐先使用 `zh-CN-XiaoyiNeural`。英文默认 `en-US-AnaNeural`，日语默认 `ja-JP-NanamiNeural`。
3. 启用原生 TTS，但把原生自动 TTS 触发概率设为 **0**，由本插件决定何时合成，避免重复语音。
4. 如需“听懂收到的语音”，在 AstrBot 中另行配置并开启 **STT 语音识别提供商**。本插件不内置 ASR 模型，也不读取或复制其他提供商的凭据。

Edge 在线语音无需在本插件填写密钥。若 STT 服务需要认证，请只在 AstrBot 提供商管理中配置自己的账户。本仓库不附带任何服务账户、生产配置或凭据。

## 后台设置

入口：**插件 → 柚铃语音助手 → 配置**。

| 设置入口 | 默认值 | 说明 |
| --- | --- | --- |
| 语音回复总开关 | 开 | 关闭后不发语音，原生识别和文字聊天仍可使用 |
| 按自动和 @分开设置 | 开 | 只改变回复形式，不增加自动回复频率或改变唤醒规则 |
| 自动回复设置 | 仅语音 | 未真正 @机器人、但原本会触发的群聊 AI 回复 |
| @回复设置 | 仅文字 | 当前消息顶层真正 @本机器人；@别人、@全体、引用内的 @ 不算 |
| 两处随机概率 | 各 20% | 仅在对应入口选择“随机”时生效；随机为仅语音或仅文字二选一 |
| 私聊／未分场景模式 | 按需 | 关闭分场景设置时也适用于群聊 |
| 群白名单 | 空 | 空为全部群，沿用机器人原有唤醒规则 |
| 单次朗读上限 | 600 字 | 可调 80—1200 字；超过时保留完整文字 |

选择“仅语音”时，只有合成成功才移除文字；合成失败、限流或内容超出朗读上限时保留原文字。明确说“只用文字”或“不要语音”时优先使用文字。

音调示例：`+0Hz` 为原音调、`+20Hz` 或 `+45Hz` 提高音调；语速示例：`+0%` 为原速、`-3%` 稍慢、`+6%` 稍快。中文参数留空时跟随原生提供商。音高调整不能保证把成年音色变成某种角色音色，请自行试听。

## 使用

```text
/语音 你好呀，今天也要开心。
/语音 Hello, nice to meet you!
/语音 こんにちは、よろしくね。
```

`/语音` 是直接朗读指定内容的独立指令，受总开关及白名单限制，不受群聊自动／@形式限制。普通聊天仍沿用原唤醒规则。分场景模式以对应入口设置为准，私聊按需模式可说“用语音回复”。

自动语言识别以每段文字为依据；纯汉字日语短句可能按中文处理，此时可在“朗读语言”中手动指定日语。插件不翻译文字，同一句内的孤立外语词仍可能按该句主要语言发音。

## 常见问题

- **只有文字**：检查总开关、对应场景、白名单、当前 TTS 提供商、会话 `/tts off`、FFmpeg 及后台日志。普通消息本来没有触发 AI 回复时，本插件不会额外触发。
- **日语后半段未读完**：检查朗读上限；混合文本会分段配音，但总长度仍受上限约束。
- **切换聊天模型后上下文混乱**：本插件保留原上下文，仅补充衔接提示；请同时检查聊天模型、会话隔离及记忆插件。
- **Edge 返回 403**：插件针对 AstrBot 4.28.2 覆盖 SDK User-Agent 的情况，在调用前恢复当前 SDK 自带请求头；不能保证外部服务永远可用。

## 数据与隐私

仓库仅包含源码、默认配置结构、测试和说明，不包含机器人账号、密钥、群号、会话、日志或录音。

语音合成会把待朗读文字发送给所选在线 TTS 服务；原生语音识别会把录音发送给所选 STT 服务。上下文衔接依赖原有聊天模型。请按自己的数据要求选择提供商。

单元测试覆盖场景识别、随机概率、失败回退、会话隔离、文本清理和混合语音拼接；不调用真实模型或在线 TTS。真实语音服务和 QQ 客户端播放仍需使用部署环境验证。
